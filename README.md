# 显微扫描出库与归还核销台（岩芯切片实验室扩展）

运行：

```bash
npm start
```

访问 `http://localhost:3025`。

## 三个业务模块

### 1. 入口（建档）
- 创建岩芯样本与初始切片（编号、染色方法、载玻片编号），新增切片。
- 修改**样本编号**或切片的**染色方法**：该切片处于「待返工」的扫描单立即失效、释放工位并进入待重排；旧扫描单与全部履历保留。
- 维护载玻片绑定、制片步骤记录与交付。

### 2. 判定（出库核对 / 归还核销）
- **出库**：每片仅允许存在一笔未归还（使用中 / 待返工）扫描单；批量整单核对切片编号、染色方法、载玻片、工位。任一缺项或冲突（编号不存在、与入口登记冲突、载玻片被占、工位被占或单内重复）→ **整单拒绝**，不落任何单、不占工位，逐行返回原因。
- **归还**：登记分辨率（≥ 2048×1536）、图像校验码（8–64 位十六进制）、操作人，并勾选是否有裂纹。任一不达标或有裂纹 → 只转「待返工」，**工位不释放**；全部通过才核销并释放工位。
- 失效单支持一键「重排出库」。

### 3. 存储（列表 / 工位 / 履历）
- 扫描单列表（使用中 / 待返工 / 已核销 / 已失效筛选）。
- 工位实况：空闲 / 使用中 / 待返工占用。
- 切片履历：制片步骤 + 全部扫描单出库、归还、失效事件。
- 列表、工位、履历均由同一份存储 (`data/core-slices.json`) 派生，刷新后保持一致。

## 主要 API
- `GET /api/state` — 样本、工位、扫描单与判定标准（单一数据源）
- `POST /api/samples` / `POST /api/samples/:id/slices` — 入口建档
- `PATCH /api/samples/:id` — 改样本编号（待返工单失效重排）
- `PATCH /api/samples/:id/slices/:sid` — 改染色方法 / 载玻片
- `POST /api/samples/:id/slices/:sid/logs`、`POST /api/samples/:id/deliver` — 制片步骤 / 交付
- `POST /api/scan-orders` — 批量出库（422 时带逐行 `details`，整单拒绝）
- `POST /api/scan-orders/:id/return` — 归还登记与核销判定
